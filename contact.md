      <h2>What to include in a first note</h2>
      <p>A useful first message answers three questions:</p>
      <ol class="steps">
        <li>What decision or process is suffering today?</li>
        <li>What happens if nothing changes in the next 6–12 months?</li>
        <li>What does the current stack look like (for example Power BI, Excel, SQL Server, Fabric, an ERP or CRM), and who owns it?</li>
      </ol>
      <p>If the problem is a fit, the usual next step is a paid BI Architecture Assessment. If it is not a fit, that will be said plainly.</p>
